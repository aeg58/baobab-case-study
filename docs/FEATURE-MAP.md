# BAOBAB Feature Map

| Product area | Capabilities | Engineering focus |
|---|---|---|
| Homepage | Hero slides and configurable content sections | Editorial control and ordering |
| Books | Metadata, categories, previews, store links | Rich catalog modeling |
| Authors | Profiles and book relationships | Many-to-many content relationships |
| Editorial | Articles, events, and workshops | Bilingual publishing workflow |
| Media | Central library, search, type management, trash | Reuse and lifecycle control |
| Discovery | Search, sales points, newsletter | Public content access |
| Internationalization | Turkish and English routes and fields | Content-level localization |
| Administration | Authentication, settings, account, dark theme | Protected editorial operations |
| SEO | Sitemap, robots, JSON-LD, structured metadata | Search-engine discoverability |
| Release | Analytics, production database, DNS/SSL, legal review | Controlled launch process |

## Deliberate Exclusions

- Proprietary source code and unpublished client content
- Production credentials and infrastructure access
- Claims of a completed cart, checkout, or online payment flow
- A public production launch before analytics, infrastructure, and legal dependencies are complete
